# Security

Please report vulnerabilities privately rather than in a public issue: use
**Security → Report a vulnerability** on this repository
(https://github.com/mrpeanut01/lead-line/security/advisories/new).

Only the latest release is supported. LeadLine is a single-user desktop app;
reports about how it handles feed and article content, the settings file
(which holds the Anthropic API key), or the release builds are especially
welcome.
